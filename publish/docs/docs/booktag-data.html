BookTagXml

XMLファイルを配置することでコアページにタグを付与することが出来ます。
条件はDeviceOfHermesのサブスクライブのみです。

HermesConfigに従って読み込みます。
フォルダ・ファイルが存在しない場合は無視します。

付与したタグはBookTagを用いて参照することが出来ます。

BookTag.xml

<BookTagXmlRoot>

    <!-- そのMODのid=10000001のコアページにタグを付与 -->
    <Book ID="10000001">
        <!-- 'Ring'を付与 -->
        <Tag>Ring</Tag>

        <!-- 'Maestro'を無効化状態で付与 -->
        <Tag>Maestro:Delete</Tag>

        <!-- 1つのコアに対して10つまで付与可能 -->
    </Book>

</BookTagXmlRoot>

BookTag.toml(ローカライズ)

# "A" = "B"
# タグAのローカライズをBとして上書きします。
# 汎用的なタグを作成する場合、他のMODからも上書きされる場合があります。
"TerminationOffice" = "終端事務所"
# 以下同じように複数実装可能です。
"SweepBeepWorkshop" = "ちり取り小鳥工房"
